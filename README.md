# smart-remote

M5Stack ATOM Lite を使い、ローカルネットワークから家電を赤外線操作するための個人開発プロジェクトです。

現在は実装より先に、購入判断と最小構成の検証ロードマップを整理しています。

## 目的

- Go CLI からローカルネットワーク経由で赤外線送信を実行する
- テレビなどの単純な赤外線操作を最小構成で動かす
- 必要になった場合だけ、外付け赤外線受信機でリモコン信号を学習する
- クラウドサービスに依存せず、自宅LAN内で完結させる

## 最初に作らないもの

- インターネット越しの遠隔操作
- MQTT、Home Assistant、スマートフォンアプリ
- ユーザーアカウントやクラウドへのログイン
- 複数メーカーの家電を最初から網羅する仕組み

## 候補ハードウェア

第一候補は M5Stack ATOM Lite（C008）です。赤外線送信機を内蔵しているため、送信だけなら追加の赤外線LED回路を省略できます。信号学習を行う場合は、別途38kHz帯の赤外線受信モジュールを追加します。

購入判断の条件と段階的な実装計画は ROADMAP.md にまとめています。

## 設計方針

- Go CLI は標準ライブラリのみを基本とする
- 実行時の通信はローカルLANに限定する
- 赤外線データ、接続先、認証情報はリポジトリに保存しない
- 初期構成は「ATOM Lite上の小さなHTTP API + Go CLI」に限定する
- 外部サービスや追加連携は、基本機能が動いてから判断する
